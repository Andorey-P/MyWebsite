# Critique Checklist — "Does This Feel Like One Artistic Vision"

Use this for judging a single page, section, or the site as a felt whole — distinct from [consistency-audit-checklist.md](consistency-audit-checklist.md), which compares *across* pages. This checklist is about whether what's in front of you right now has a coherent point of view on its own terms, independent of whether other pages match it.

Work through every section in order. Don't skip to "give a verdict" — the value of this checklist is in forcing each question to be answered specifically, with evidence, rather than arriving at a gut-feel score.

## 1. Point of view test

- [ ] State the one-adjective mood this is going for (per [docs/design-philosophy.md](../docs/design-philosophy.md)) *before* looking at any more detail. If you can't state one, that's the finding — the piece doesn't have a legible point of view yet, and every check below will surface symptoms of that same root problem.
- [ ] Does every major visual decision you can point to (color, type, motion, density) support that adjective, or fight it? Name any that fight it specifically.
- [ ] Could this exact page, with only the logo/name swapped, belong to a different person/brand with a different point of view? If yes, the point of view isn't distinct enough yet — see [docs/design-philosophy.md](../docs/design-philosophy.md)'s "one adjective a competitor wouldn't use" test.

## 2. Mood translation test

- [ ] Run the six-question translation from [docs/art-direction-mood.md](../docs/art-direction-mood.md) (color temperature, type voice, motion character, density, material, sound-adjacent register) against what's actually on screen. Do all six answers agree with each other, or does one contradict the rest (e.g. cool clinical color paired with loose bouncy motion)?

## 3. Composition test

- [ ] Where does the eye land first? Second? Third? (Per [docs/composition-balance.md](../docs/composition-balance.md).) If there's no clear sequence, or several elements compete equally for first attention, that's a specific, nameable finding.
- [ ] Is negative space doing work (pacing, isolation, focal support), or is it just whatever's left over after content was placed?
- [ ] Strip the composition down to its single most important element only — does the frame still feel intentional, or does it look like an accident that happens to contain one good thing?

## 4. Color and type discipline test

- [ ] Count the colors actually in use. Is it within the 3–5 budget from [docs/color-palette-rationale.md](../docs/color-palette-rationale.md)? If over budget, which color snuck in without a stated job?
- [ ] Is the accent color still rare enough to function as a focal signal, or has it crept into decorative use everywhere, diluting its own effect?
- [ ] Are there more than two type families in active use (display, body, optional mono)? If more, which one doesn't have a stated reason to exist?

## 5. Interaction honesty test

- [ ] Does the motion register (per [docs/interaction-philosophy.md](../docs/interaction-philosophy.md)) match the stated mood, or does it default to whatever felt smooth to build rather than what the mood calls for?
- [ ] Are there more than 2–3 "signature" interaction moments competing for memorability? If everything is trying to be a standout interaction, none of them will be remembered as one — name which one *should* be the signature and which others should be quieted.

## 6. The "so what" test

- [ ] After the full pass above, can you state — specifically, not generically — what a viewer should remember five minutes after leaving this page (per [docs/design-philosophy.md](../docs/design-philosophy.md))? If the honest answer is "it was nice" or "it was competent," that's a finding: competent execution without a memorable thesis is the single most common failure mode in this genre, and it's worth naming directly rather than softening it.

## Verdict framing

Close with a direct verdict, not a hedge: does this cohere as one artistic vision, yes or no, and if no, name the single highest-leverage fix (usually one of: pick a sharper mood adjective, cut the color/type budget back down, resolve a specific composition ambiguity, or quiet down competing interaction moments) — not a list of five equally-weighted nitpicks. Use [templates/design-critique-template.md](../templates/design-critique-template.md) to structure the written output.
