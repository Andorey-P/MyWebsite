# Copywriting Checklist

Sentence-level pass. Apply after structure is settled — this checklist assumes the section order and content are already right (see [portfolio-flow-checklist.md](portfolio-flow-checklist.md) / [case-study-checklist.md](case-study-checklist.md) for structure). Full rationale in [../docs/copywriting-voice.md](../docs/copywriting-voice.md).

## Specificity

- [ ] Every adjective-driven claim ("skilled," "detail-oriented," "innovative") is replaced with, or immediately followed by, a checkable fact
- [ ] No sentence could be pasted unchanged onto a competitor's portfolio and still sound true
- [ ] Concrete nouns used instead of placeholder nouns ("interactive product configurators" not "immersive experiences")
- [ ] Real numbers used wherever they genuinely exist (draw calls, load time, fps, award names) — and never fabricated where they don't

## Banned words

- [ ] None of: `passionate`, `innovative`, `cutting-edge`, `seamless`, `leverage` (as a verb), `utilize`, `synergy`, `state-of-the-art`, `world-class`, `game-changing`, `disruptive`, `next-level`, `unique` (without a following "because"), `robust`, `results-driven`, `detail-oriented`
- [ ] "Dynamic," "solution," "content," "experience" checked for whether they're doing real work or filling space

## Voice & grammar

- [ ] Active voice — actor is named ("I built," not "was built")
- [ ] First person, consistent across the site (no third-person slip on the about page if the rest is first-person)
- [ ] Tense is consistent within a section (present for general claims, past for specific project narration)
- [ ] No intensifiers/hedges doing the work a stronger base word should do (`very`, `really`, `quite`, `somewhat`)
- [ ] No throat-clearing openers ("In this project, I want to talk about...")

## Rhythm

- [ ] Sentence length varies — not a flat run of same-length declaratives
- [ ] At least one short, confident sentence breaks up longer explanatory ones per section

## Jargon discipline

- [ ] Every named technology is attached to the decision it served, not listed as a standalone credibility flex
- [ ] No sentence stacks 3+ tool names with no explanation of what each one did

## Final self-check

- [ ] Read each key sentence and ask: "could this be pasted onto someone else's portfolio unchanged and still sound true?" — if yes, rewrite for specificity
- [ ] Read the whole page aloud once — anything that doesn't sound like a person talking gets flagged
